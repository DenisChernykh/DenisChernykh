## Избранные проекты

### [Social Analytics](https://github.com/DenisChernykh/social-analytics-service)

Сервис аналитики с интеграцией официального Instagram API и отчётами в ChatGPT. Реализовал сбор и историю показателей, фоновые задания с восстановлением и MCP-инструменты.

**Результат оптимизации:** в контрольном сравнении на рабочей БД расчёт статуса прочитал на 92% меньше строк при совпадающих ответах — 5 493 вместо 71 140. [Методика и результаты](https://github.com/DenisChernykh/social-analytics-service/blob/main/docs/collection-status-counters.md).

TypeScript · Hono · Drizzle · Cloudflare Workers/D1/Durable Objects · MCP

### [Давай вместе — Collaboration Bot](https://github.com/DenisChernykh/collab-bot)

Telegram-сервис для поиска сотрудничества и знакомств: многошаговые анкеты на русском и английском, сохранение черновиков, запросы на знакомство и обмен контактами после взаимного согласия.

**Фестивальный запуск:** зафиксированы 45 заполненных анкет и 19 запросов на знакомство. После завершения фестиваля сохранены профили и история взаимодействий.

TypeScript · grammY · Cloudflare Worker · SQLite Durable Object
